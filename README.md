# project-Garage

ระบบ Good Garage แอปพลิเคชันบริหารจัดการอู่ซ่อมรถ

## Features

- ระบบสมาชิก ลูกค้า / อู่ / ช่าง / Admin
- ค้นหาอู่ซ่อมรถ
- ส่งคำขอซ่อมรถ
- ติดตามสถานะการซ่อม
- ระบบใบเสนอราคา
- ระบบชำระเงิน
- ระบบแชท
- ระบบรีวิวและคะแนน

## Technology

- Flutter
- Dart
- Node.js
- MySQL
- REST API
- Socket.IO
